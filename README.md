# Currency Exchange

Проект представляет собой REST API для работы с валютами и курсами обмена. Приложение позволяет управлять списком валют, добавлять и обновлять курсы обмена, а также рассчитывать конвертацию между различными валютами.

## Используемые технологии

- Python 3.14
- SQLite
- HTTP Server
- Docker

## Функциональность

- Получение списка всех валют.
- Получение информации о конкретной валюте.
- Добавление и удаление валют.
- Получение списка всех курсов обмена.
- Получение курса обмена между двумя валютами.
- Добавление, обновление и удаление курсов обмена.
- Конвертация денежных сумм между валютами.
- Расчёт курсов при отсутствии прямого курса обмена.
